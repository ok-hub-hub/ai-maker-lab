## まず「ゴール」を決める（ここを飛ばすと後悔する）

独学かスクールかを選ぶ前に、**何のためにエンジニアになりたいのか**を言語化してください。これが曖昧なまま進むと、どちらのルートでも途中で迷子になります。

### ゴールの種類と、それに合うルート

- **「Web系の会社に正社員で転職したい」**：転職エージェントに相談して、今の状態で求人があるか確認するのが最初の一歩。スクールが必要かどうかはそこで判断できます。
- **「副業でWeb制作の仕事を取りたい」**：独学 or 安価なスクールで十分な場合が多い。ポートフォリオ1〜2本で案件獲得している人も実在する。
- **「フリーランスエンジニアになりたい」**：まず1〜2年間の実務経験が必要になることがほとんど。ゴールから逆算すると「まず正社員転職」が近道になるケースが多い。
- **「AIエンジニアとして働きたい」**：機械学習・MLエンジニアはハードルが高い。まずITエンジニア（SIer・Web系）として実務経験を積む流れが一般的。

## 独学のリアル：できること・限界・向く人

### 独学でできること

- HTML / CSS / JavaScript の基礎：YouTube・Progate・Udemy（数百〜数千円）で習得できる範囲
- Webアプリの「作ってみた」レベル：ポートフォリオとして見せられる成果物を作れる
- AI ツールを使った加速：ChatGPT・Claude・Copilot で「エラーの解決」「コードの説明」を補える（これが2026年現在の独学の強み）

### 独学の限界

- **フィードバックがない**：コードを書いても、それが「実務で通用するか」を判断できる人がいない
- **詰まったときに止まる**：エラーで数日動けなくなる。AIが解決してくれることも増えたが、設計レベルの問題には限界がある
- **転職の「見せ方」が分からない**：ポートフォリオを作っても、それをどう書類・面接でアピールするかのノウハウが独学では得にくい

### 独学が向く人

✅ 毎日1〜2時間以上、継続して手を動かせる自律性がある  
✅ まずは副業や案件獲得から試したい（正社員転職が急務でない）  
✅ AIツールを使いながら効率的に学べる（このサイトの読者層に近い）  
✅ スクール費用の余裕が今はない

## スクールのリアル：何が変わるか・向く人

### スクールで変わること

- **カリキュラムの構造**：「何を・どの順で学ぶか」が設計されており、独学の「何から始めるか問題」をスキップできる
- **フィードバックループ**：課題提出→レビューのサイクルで、「実務的なコードとのギャップ」を早期に潰せる
- **転職支援**：求人紹介・書類添削・面接練習まで含むスクールが多い（成果を保証するものではない）

### スクールの注意点

- **費用は必ず公式で確認する**：相場は十数万〜数十万円と幅が大きく、本記事では特定の金額を断定しません。無料相談で最新の料金・コース構成を確認してください
- **完走に時間がかかる**：週20〜30時間程度の学習を3〜6ヶ月続ける必要がある設計が多い。在職中に並行するのはかなりの負荷
- **スクールを出れば転職できるわけではない**：あくまで「スキル習得と転職活動の支援」であり、結果は保証されない

### スクールが向く人

✅ 独学で挫折した経験がある、またはサポートがないと続かない  
✅ 「体系的に学んで実務レベルに持っていく」ことを最優先にしている  
✅ 転職サポートまで含めてまとめて完結させたい  
✅ スクール費用を用意できる（または教育ローンを検討できる）

## 独学 vs スクール 比較表

| 項目 | 独学 | プログラミングスクール |
|-----|------|---------------------|
| **費用** | 数千〜数万円（教材費） | 数十万円〜（公式で要確認） |
| **期間の目安** | 自分次第（3ヶ月〜1年以上） | カリキュラムに沿って3〜6ヶ月が多い |
| **フィードバック** | なし（AIで一部補える） | メンター・課題レビューあり |
| **転職支援** | 自力 | 多くのスクールに含まれる |
| **挫折リスク** | 高い（途中でやめやすい） | カリキュラム・サポートで補える |
| **AI活用との相性** | ◎（AIで自己解決の幅が広がった） | ○（スクールによって差がある） |
| **向く目的** | 副業・まず試す・低コスト | 本格転職・基礎から一気に完成 |

## FAQ

**Q. 独学どのくらいで転職できる？**  
A. 保証はできません。「独学◯ヶ月で転職成功」という事例は実在しますが、スキルの到達度・ポートフォリオの質・求人市場の状況・応募数などが結果に影響します。目安として「最初の求人応募が可能な状態になるまで6〜12ヶ月」という声は多いですが、個人差が大きいです。転職エージェントに現状を話すと、より具体的な感触を得られます。

**Q. スクールに入れば転職できる？**  
A. スクールはスキル習得と転職活動を支援するサービスであり、転職を保証するものではありません。公式が「転職保証」と記載している場合も、条件・除外事項を必ず確認してください。

**Q. AIツールを使って独学できる？**  
A. 可能です。2026年現在、ChatGPT・Claude・GitHub Copilot などを使うと、エラー解決・コードの説明・設計の相談をAIに任せられる範囲が大きく広がっています。ただし「AIが全部やってくれる」わけではなく、基礎的な読み書き力は人間が持つ必要があります。

**Q. スクールの料金はいくら？**  
A. スクールによって大きく異なり、本記事では特定の金額を断定しません。**必ず公式サイトで最新料金を確認してください**（料金は改定される場合があります）。無料相談で確認するのが確実です。

**Q. 転職エージェントは本当に無料？**  
A. type転職エージェント・明光キャリアパートナーズなどの転職エージェントは、採用企業側から報酬を得るモデルのため、**求職者は無料で利用できます**。ただしスクールの受講費用は別途かかります（スクールは教育サービスのため）。

- **独学** は低コスト・自由だが、挫折リスクが高く転職支援がない。副業や「まず試す」用途に向く。
