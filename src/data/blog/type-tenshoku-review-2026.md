## type転職エージェントとは（概要・データ）

type転職エージェントは、**株式会社キャリアデザインセンターが運営する総合型転職エージェント**です。IT・Web業界を中心に、営業・マーケティング・経営・事務・販売・接客・技術職など幅広い職種に対応しています。

| 項目 | 内容（公式サイト記載・2026年8月23日確認） |
|------|----------------------------------------|
| 公開求人数 | 38,122件（公式サイト記載の数値） |
| 非公開求人数 | 23,183件（同） |
| 非公開求人率 | 約60% |
| 転職後の定着率 | 97.4%（2023年4月〜2024年3月実績） |
| 年収アップ | 約5人に4人が実現（公式記載） |
| キャリアカウンセリング | 約1.5時間（電話は30分〜1時間） |
| 対応時間 | 平日夜間・土曜日対応 |
| 対応エリア | 全国（オンライン・電話面談対応） |
| 料金 | 完全無料（登録から入社まで） |

「選び方・受かり方・決め方」の3軸で手厚いサポートを提供する設計です。求人の約60%が非公開求人であるため、求人サイトで検索するだけでは見つけられない選択肢が一定数あります。

## 良い評判・強みと思う点

### 1. 求人の絶対数が多い・非公開求人が約60%

公開求人38,122件＋非公開求人23,183件の合計6万件超（公式サイト記載）は、IT特化型エージェントと比較しても規模が大きい部類です。特に**非公開求人が約60%**という点が重要で、「求人サイトで検索して終わり」では出会えない求人が相談を通じて紹介されます。

初めての転職活動で「自分にどんな選択肢があるかわからない」段階では、絶対数の多いエージェントで幅を把握してから方向性を絞るのが有効です。

### 2. 定着率97.4%・5人に4人が年収アップ（公式記載）

転職後に後悔しないか、長く続けられるかは、エージェント選びの重要な基準の1つです。公式サイトには**転職後の定着率97.4%**（2023年4月〜2024年3月）および「約5人に4人が年収アップを実現」と記載されています。

数値として確認できる根拠を持つエージェントは信頼性の指標になります。ただしこれは統計であり、**あなた個人の転職後定着・年収アップを保証するものではありません**。実際の結果は経歴・希望条件・応募先・市況によって異なります。

### 3. 全職種対応で「IT転職以外の選択肢」も同時に見られる

type転職エージェントは、IT・Web業界に加え、営業・マーケティング・経営・事務・販売・接客・技術職など幅広い職種をカバーしています。

「AIを活かせる仕事に転換したいが、エンジニア職だけでなくDXプロジェクト管理・マーケティング・AI活用推進職も視野に入れている」という方には、IT特化型エージェントより選択肢の幅が広がります。AIリテラシーへのニーズはエンジニア職に限らず広がっており、type転職エージェントはその受け皿になりえます。

### 4. 平日夜間・土曜日対応で在職中でも動きやすい

「仕事が終わってから相談したい」「週末しか動けない」というニーズに対応しています。来社不要・オンライン対応のため地方在住でも利用可能です。キャリアカウンセリングは約1.5時間（電話は30分〜1時間）と、初回から深い話ができる設計になっています。

## 正直な弱点・注意点

### 1. 総合型のため「IT特化」の深さはない

IT・Web業界の求人は多数扱いますが、**TechGoのような「ITエンジニア経験者のハイクラス転職特化」の深さはありません**。上流工程・アーキテクト・プリンシパルエンジニアなどのハイクラス転職を突き詰めたい場合は、IT特化型エージェントを主軸に置くほうが効率的です（[TechGo](/go/techgo)）。

### 2. 実務未経験からのエンジニア転職には向かない

「独学でプログラミングを学んでいる」「個人開発の経験のみ」という段階では、総合型のtype転職エージェントは合いません。未経験からITエンジニアを目指す方には、IT/エンジニア転職専門の**[明光キャリアパートナーズ](/go/meiko-career)**が設計上向いています。

### 3. 紹介求人は経歴・エリア・市況で変わる

「6万件以上の求人がある」としても、自分の経歴・希望条件・エリアに合う求人が必ず紹介されるわけではありません。求人保有状況は時期によっても変動します。面談を実際に受けて「どんな求人が来るか」を確かめるのが最も確実な判断材料です。

> それでも**無料で相談できる**のは大きなメリットです。合わなければ進めなくて構いません。

## 面談前に用意しておくと良いもの

面談の質を上げるために、事前に整理しておくことをすすめます。

1. **現在の仕事・職歴のメモ**：業種・役職・業務内容・在籍期間など。「何年・何をやってきたか」をおおまかにまとめておくと話がスムーズです。
2. **転職の希望軸**：「IT業界に入りたい」「年収〇〇万円以上」「リモート勤務希望」など、優先順位をつけておくと求人マッチングの精度が上がります。
3. **AIツールの活用経験**：業務でChatGPT・Claude・NotionAIなどを使っている場合、「何に使い、何が変わったか」を整理しておくと市場価値として語れる場合があります。「使っています」より「業務でXXをYYに削減した」という具体性が重要です。
4. **転職の時軸**：「今すぐ」「3〜6ヶ月後」「まだ決めていない」など。決まっていなくても相談は可能です。情報収集だけの動機でもOKです。

## FAQ

**Q. type転職エージェントの面談だけ受けて、申し込まなくてもいい？**
A. 大丈夫です。キャリア相談・面談は転職活動の契約ではなく情報収集の場です。合わなければ進めなくてOKです。「転職するか決めていない」段階でも参加できます。

**Q. 非IT職でもIT・Web業界の求人を紹介してもらえますか？**
A. 対応しています。type転職エージェントは全職種対応で、非IT職からの転職者にも求人紹介を行っています。ただし紹介される求人の内容は経歴・希望・時期の市況によって変わります。実際に面談で確認するのが最も確実です。

**Q. type転職・TechGo・明光、どれに登録すればいい？**
A. 状況によって分かれます。「ITエンジニアの実務経験があり上流・年収アップを狙う」→ TechGo。「実務未経験でエンジニアを目指す」→ 明光キャリアパートナーズ。「幅広い選択肢を見たい・非IT職からIT転職を検討している」→ type転職エージェントが設計上向いています。複数の並行利用も一般的です。

**Q. 料金はいくら？**
A. 求職者は完全無料です。転職エージェントは採用企業側から報酬を得るモデルのため、求職者に費用は発生しません。最新の利用条件は[公式サイト](/go/type-tenshoku)でご確認ください。

**Q. 地方在住でも利用できますか？**
A. 全国対応しています。オンライン・電話での面談に対応しているため、地方在住でも相談できます。紹介求人のエリアは地域の求人市況によりますので、リモート可求人の有無は公式でご確認ください。

**Q. 転職したら年収が上がりますか？**
A. 保証できません。公式サイトには「約5人に4人が年収アップ」との記載がありますが、これはあなた個人の年収アップを保証するものではありません。結果は経歴・市況・応募先によって大きく異なります。

- type転職エージェントは**全職種対応の総合型転職エージェント**。公開求人38,122件・非公開求人23,183件・非公開求人率約60%（公式サイト記載）で求職者は完全無料。
